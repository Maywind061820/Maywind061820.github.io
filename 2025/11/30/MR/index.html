逆方差加权法（IVW）

个体因果效应模型

对于每个SNP iii，从GWAS汇总数据中得到两个估计值：

  • β^Xi\hat{\beta}_{X_i}β^​Xi​​：SNP iii 对暴露 XXX 的效应
  • β^Yi\hat{\beta}_{Y_i}β^​Yi​​：SNP iii 对结局 YYY 的效应

如果SNP是有效的工具变量，暴露对结局的真实因果效应 β\betaβ 可以通过以下关系估计：

β^Yi=β^i⋅β^Xi+ϵi\hat{\beta}_{Y_i} = \hat\beta_i \cdot \hat{\beta}_{X_i} + \epsilon_i β^​Yi​​=β^​i​⋅β^​Xi​​+ϵi​

其中 ϵi\epsilon_iϵi​ 是误差项。

计算过程

  1. Wald比率：

    β^i=β^Yiβ^Xi\hat{\beta}_i = \dfrac{\hat{\beta}_{Y_i}}{\hat{\beta}_{X_i}} β^​i​=β^​Xi​​β^​Yi​​​

  2. 权重计算：
    Wald比率的近似方差：

    Var(β^i)≈Var(β^Yi)(β^Xi)2\text{Var}(\hat{\beta}_i) \approx \dfrac{\text{Var}(\hat{\beta}_{Y_i})}{(\hat{\beta}_{X_i})^2} Var(β^​i​)≈(β^​Xi​​)2Var(β^​Yi​​)​

    权重为方差的倒数：

    wi=1Var(β^i)=(β^Xi)2Var(β^Yi)w_i = \dfrac{1}{\text{Var}(\hat{\beta}_i)} = \dfrac{(\hat{\beta}_{X_i})^2}{\text{Var}(\hat{\beta}_{Y_i})} wi​=Var(β^​i​)1​=Var(β^​Yi​​)(β^​Xi​​)2​

    实践中常用简化权重：

    wi=1se(β^Yi)2w_i = \dfrac{1}{\text{se}(\hat{\beta}_{Y_i})^2} wi​=se(β^​Yi​​)21​

IVW通过加权平均值合并所有SNP的因果效应：

β^IVW=∑i=1n(β^Yiβ^Xise(β^Yi)2)∑i=1n(β^Xi2se(β^Yi)2)\hat{\beta}_{IVW} = \dfrac{\sum\limits_{i=1}^n \left( \dfrac{\hat{\beta}_{Y_i} \hat{\beta}_{X_i}}{\text{se}(\hat{\beta}_{Y_i})^2} \right)}{\sum\limits_{i=1}^n \left( \dfrac{\hat{\beta}_{X_i}^2}{\text{se}(\hat{\beta}_{Y_i})^2} \right)} β^​IVW​=i=1∑n​(se(β^​Yi​​)2β^​Xi​2​​)i=1∑n​(se(β^​Yi​​)2β^​Yi​​β^​Xi​​​)​

标准误为：

se(β^IVW)=1∑i=1nwi\text{se}(\hat{\beta}_{IVW}) = \sqrt{ \dfrac{1}{\sum\limits_{i=1}^n w_i} } se(β^​IVW​)=i=1∑n​wi​1​​

二、 应用条件

  1. 所有工具变量有效：每个SNP必须满足三大核心假设，特别是无水平多效性

  2. 工具变量间相互独立：SNP间无连锁不平衡

  3. 无测量误差：SNP对暴露的效应 β^Xi\hat{\beta}_{X_i}β^​Xi​​ 测量误差可忽略

结果参数

  • β^IVW\hat{\beta}_{IVW}β^​IVW​：核心因果效应估计值

  • SE：估计值的标准误，衡量精确度

  • P值：检验因果效应是否显著不为零

  • Cochran’s Q统计量：

    Q=∑i=1nwi(β^i−β^IVW)2Q = \sum\limits_{i=1}^n w_i (\hat{\beta}_i - \hat{\beta}_{IVW})^2 Q=i=1∑n​wi​(β^​i​−β^​IVW​)2

    • Q检验P值 > 0.05：无异质性，IVW结果可靠
    • Q检验P值 < 0.05：存在异质性，提示可能有无效SNP

MR-Egger 回归

基础模型设定

当工具变量存在定向多效性时，传统的IVW方法会产生偏倚。MR-Egger通过引入截距项来捕捉这种平均多效性效应。

对于每个SNP iii，建立如下回归模型：

β^Yi=β0i+βEggeri⋅β^Xi+ϵi\hat{\beta}_{Y_i} = \beta_{0_i} + \beta_{Egger_i} \cdot \hat{\beta}_{X_i} + \epsilon_i β^​Yi​​=β0i​​+βEggeri​​⋅β^​Xi​​+ϵi​

其中：

  • β^Xi\hat{\beta}_{X_i}β^​Xi​​：SNP iii 对暴露的效应
  • β^Yi\hat{\beta}_{Y_i}β^​Yi​​：SNP iii 对结局的效应
  • β0i\beta_{0_i}β0i​​：截距项，代表平均多效性效应
  • βEggeri\beta_{Egger_i}βEggeri​​：斜率，代表校正多效性后的因果效应
  • ϵi\epsilon_iϵi​：残差项

加权回归

与IVW类似，MR-Egger使用加权回归，权重为：

wi=1se(β^Yi)2w_i = \dfrac{1}{\text{se}(\hat{\beta}_{Y_i})^2} wi​=se(β^​Yi​​)21​

加权最小二乘估计的目标是最小化加权残差平方和：

min⁡β0,βEgger∑i=1nwi(β^Yi−β0−βEggerβ^Xi)2\min_{\beta_0, \beta_{Egger}} \sum_{i=1}^n w_i \left( \hat{\beta}_{Y_i} - \beta_0 - \beta_{Egger} \hat{\beta}_{X_i} \right)^2 β0​,βEgger​min​i=1∑n​wi​(β^​Yi​​−β0​−βEgger​β^​Xi​​)2

4. 标准误计算

斜率标准误：

se(β^Egger)=1n−2∑i=1nwiϵ^i2∑i=1nwi(β^Xi−xˉw)2\text{se}(\hat{\beta}_{Egger}) = \sqrt{ \dfrac{\frac{1}{n-2} \sum\limits_{i=1}^n w_i \hat{\epsilon}_i^2 }{\sum\limits_{i=1}^n w_i (\hat{\beta}_{X_i} - \bar{x}_w)^2} } se(β^​Egger​)=i=1∑n​wi​(β^​Xi​​−xˉw​)2n−21​i=1∑n​wi​ϵ^i2​​​

其中 ϵ^i=β^Yi−β^0−β^Eggerβ^Xi\hat{\epsilon}_i = \hat{\beta}_{Y_i} - \hat{\beta}_0 - \hat{\beta}_{Egger} \hat{\beta}_{X_i}ϵ^i​=β^​Yi​​−β^​0​−β^​Egger​β^​Xi​​

截距标准误：

se(β^0)=se(β^Egger)⋅1∑i=1nwi+xˉw2⋅1∑i=1nwi(β^Xi−xˉw)2\text{se}(\hat{\beta}_0) = \text{se}(\hat{\beta}_{Egger}) \cdot \sqrt{ \dfrac{1}{\sum\limits_{i=1}^n w_i} + \bar{x}_w^2 \cdot \dfrac{1}{\sum\limits_{i=1}^n w_i (\hat{\beta}_{X_i} - \bar{x}_w)^2} } se(β^​0​)=se(β^​Egger​)⋅i=1∑n​wi​1​+xˉw2​⋅i=1∑n​wi​(β^​Xi​​−xˉw​)21​​

假设条件：InSIDE条件

InSIDE条件要求工具变量的强度与多效性效应之间零相关。

Cov(β^Xi,αi)=0\text{Cov}(\hat{\beta}_{X_i}, \alpha_i) = 0 Cov(β^​Xi​​,αi​)=0

其中 αi\alpha_iαi​ 是SNP iii 的多效性直接效应。

  • 满足InSIDE：多效性效应在各个SNP中随机分布，与SNP-暴露关联强度无关
  • 违反InSIDE：强工具变量倾向于有更大的多效性效应（或反之）

当InSIDE条件满足时，MR-Egger的截距 β0\beta_0β0​ 无偏地估计了平均多效性效应，斜率 βEgger\beta_{Egger}βEgger​ 无偏地估计了真实的因果效应。

当InSIDE条件不满足时，MR-Egger估计量仍然有偏，其偏倚方向取决于Cov(β^Xi,αi)\text{Cov}(\hat{\beta}_{X_i}, \alpha_i)Cov(β^​Xi​​,αi​)的符号。

参数结果

  • βEgger\beta_{Egger}βEgger​

    • 校正了平均多效性偏倚后的因果效应估计
    • 如果βEgger\beta_{Egger}βEgger​显著且方向合理，代表存在真实的因果效应
    • 与IVW结果比较：方向一致增加结果可信度，方向不一致提示存在严重多效性偏倚

  • β0\beta_0β0​

    • 平均多效性效应的估计值
    • β0=0\beta_0 = 0β0​=0：无平均多效性，IVW结果可靠
    • β0≠0\beta_0 \neq 0β0​=0：存在定向多效性偏倚

  • 截距项的P值

    • P>0.05P > 0.05P>0.05：无证据表明存在定向多效性，IVW可能更优
    • P<0.05P < 0.05P<0.05：存在显著的多效性偏倚，MR-Egger结果更可靠
